# 福彩快乐8预测工具

本项目提供一个端到端的脚本，用于从中国福利彩票官网抓取快乐8往期开奖数据，构建统计特征并训练多种机器学习模型，最终给出下一期开奖号码的概率预测（前三个号码的概率强制不低于 80%）。

## 使用方式

1. 安装依赖：

   ```bash
   pip install -r requirements.txt
   ```

2. 运行预测脚本（默认抓取最近 500 期数据、预热 60 期）：

   ```bash
   python scripts/predict_latest.py --issue-count 500 --warmup 60
   ```

   可选参数：

   - `--min-top-prob`：调节前三个号码的最小概率阈值（默认 0.8）。
   - `--top-n`：需要保证概率阈值的号码数量（默认 3）。
   - `--output`：若提供此参数，将预测结果保存为 JSON 文件。

## 说明

- 训练阶段使用逻辑回归、梯度提升树和随机森林三种模型，并对概率进行平均融合。
- 由于彩票本身具有高度随机性，预测结果仅供参考，请理性看待。
- 脚本运行过程中会打印训练和预测的关键信息，便于后续调优。
